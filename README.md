## Design rules

- **Gold:** logo, nav, and pricing JOIN cards only
- **Electric blue (`#1DBCCD`):** all other accents and CTAs
- **Bornia** sitewide
- **No icons** in page content
- Hero: single primary CTA
- Sticky bottom CTA retained
